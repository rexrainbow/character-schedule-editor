# 時段行程模擬

專案選單提供第三種「模擬模式」。第一版只執行所選時段行程，不推進時段、星期或周序列；求值器獨立於 React，位於 `src/simulationModel.js`。

## 操作

1. 選擇時段行程，旁邊的跳轉 icon 可開啟共用定義編輯器。
2. 依群組調整環境與應用變數的測試數值。首次使用採專案初始值；唯讀變數也可設定測試輸入。計算式巨集顯示即時求值結果，不直接輸入。
3. 按「執行模擬」，查看執行紀錄與變數變更。每次執行從目前輸入重新開始，前一次執行不會自動改變輸入。
4. 「套用執行後數值」明確將成功結果作為下一次測試輸入；「重設輸入」恢復專案初始值。兩者均不修改專案。

桌面以輸入／結果雙欄呈現，各欄獨立捲動；手機以輸入／結果頁籤切換。結果內另有執行紀錄／變數變更頁籤。繁體中文與英文介面皆支援。

## 執行規則

- 依序判斷時段分支，第一個成立者執行，後續分支標示未求值。最後 ELSE 保留原規則。
- ALL／ANY 採短路求值，跳過項目明確標示未求值。型別、比較運算、除以零及非有限結果均檢查，錯誤附資料位置並停止執行。
- 數字 expression、兩層計算式巨集、巨集局部參數均支援。計算式按當下狀態重新求值，不快取跨任務的結果。
- 計算式巨集支援分支回傳：依序判斷條件、只求值選中結果，顯示回傳值與未求值結果；未選中結果的除以零不造成當次模擬失敗。
- 分支巨集可選任務或序列巨集，序列按步驟執行 primitive／內建任務；保留原呼叫模式及參數契約限制。引用型別參數保持位置引用，不轉成變數內容。
- 空巨集記錄「正在執行：名稱／沒有動作，完成」。
- 空時段行程（`branches: []`）同樣顯示活動名稱與沒有動作，不產生任務呼叫；可用於僅依行程名稱運作的 runtime。
- 時段行程、分支任務巨集與計算式巨集只有一個 ELSE 時，執行紀錄省略分支外框，直接顯示任務或回傳值。有條件分支時，ELSE 顯示「其餘條件皆不成立」，不顯示 true；未執行的分支仍標示未求值。任務統一顯示「正在執行：名稱」。此呈現不改變求值規則及資料格式。
- 四個內建變數操作在模擬副本執行，仍禁止任務寫入 read_only 變數。後續步驟及引數會讀到先前更新的值。
- 重設初始值使用專案定義的 initial_value 作基準；手動修改測試輸入不改變此基準。環境層實際 engine 初始化政策尚未模擬。
- 一般環境任務以「正在執行」呈現預計呼叫、參數與變數引用，不呼叫外部 engine。其副作用未知，後續求值明確假設變數不變，結果顯示此假設。
- 每次求值最多 20,000 次操作、64 層巢狀，計算式循環會報錯。錯誤保留已產生的部分紀錄與變更，禁止套用失敗結果。

## 資料隔離

模擬輸入、選取、頁籤及結果屬於 App 的獨立工作狀態。切換編輯模式可保留情境，專案修改會清除舊結果，重新執行才產生新紀錄。新建／匯入專案清除模擬情境。

模擬不更改專案初始值、時段指定、定義或未儲存旗標，不加入 project、environment、runtime JSON，也不直接執行一般任務。新增變數採其初始值；被刪除的變數不再列入輸入。變數型別變更若造成既有測試輸入不相容，會顯示錯誤，可重設輸入修正。

後續周序列推進可以獨立解析下一個時段行程及更新進度變數，再呼叫同一個 `simulateSlot` 求值器。
