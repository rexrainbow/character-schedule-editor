# 任務巨集與共通資格條件

參數另支援「選項」型別。可定義選項名稱及字串值，呼叫時以 dropdown 選擇，或轉傳相容巨集參數。選項參數在比較式中視為字串，完整規則見 [ENUM_PARAMETERS.md](./ENUM_PARAMETERS.md)。

任務巨集屬於應用層，具有 UUID、必填 name、選填 display_name、icon、參數介面及可選的資格條件。模式只決定通過資格條件後如何執行。

| mode | 介面名稱 | 行為 |
| --- | --- | --- |
| sequence | 任務序列 | 依序執行所有步驟 |
| branch | 分支任務 | 第一個條件成立的分支執行，最後保留 ELSE |
| priority | 優先候選 | 依序選擇第一個資格條件成立的候選巨集 |

## 資格條件

三種模式均在參數介面之後、任務內容之前提供「資格條件」。預設收合；未設定顯示「無限制」，設定後收合列顯示條件摘要。收合不會停用條件。展開後可設定、編輯或清除，使用共用 ConditionEditor；新增時提供 `0 == 0` 作為可編輯起點。

專案欄位為 `eligibility: Condition | null`，省略或 null 都表示無限制，不儲存隱藏的預設比較式。條件支援 ALL／ANY、比較、數字運算、環境／應用變數、計算式巨集與自己的參數。

每次呼叫先求值引數，再於巨集自己的參數作用域檢查資格條件。成立才進入內容，不成立就略過整個巨集，呼叫方的下一步照常執行。前面步驟的變數更新會影響後續巨集的資格。條件或引數求值錯誤會停止並回報位置，不當成不符合。

例如「工作」可直接保存 `資格條件：體力 >= 10`，步驟為減少體力、增加金錢，不必再建立同名的條件包裝。

## 優先候選

時段行程也可以[直接編輯優先候選](./SLOT_PRIORITY.md)，與本模式共用清單介面及求值規則，不必先建立一個優先候選巨集。

候選清單可排序、複製、刪除，每項可引用任務序列、分支任務或優先候選巨集。填入被引用巨集的引數，顯示其資格條件摘要，並提供跳至原定義按鈕。修改原資格條件會影響所有引用者。可重複引用同一巨集並傳入不同引數。

專案保存 `candidates: [{id: UUID, task: {task_macro_id: UUID, arguments: {...}}}]`。候選不另外儲存條件；只能引用巨集，不能直接選一般／內建任務。空候選清單合法。

依清單順序為候選求值引數、檢查資格條件，第一個成立者直接執行內容，不重複求值引數或資格條件。後續候選的引數、條件與內容均不求值。全部不符合時沒有動作。

未設定資格條件的巨集永遠符合，可放最後作為保底；若放前面，後續候選就不會被選中。選中空巨集，或選中的優先候選巨集內部沒有任何候選符合，仍代表外層選擇完成，不繼續嘗試外層後續項目。

## 呼叫、維護與轉換

時段行程、任務序列及分支動作可呼叫任何巨集模式，允許序列呼叫序列等組合，但禁止直接或間接循環。選單排除會形成循環的目標，匯入／提交驗證也會回報呼叫位置。

切換模式會確認丟棄原步驟／分支／候選內容，保留名稱、參數、資格條件、圖示與 name。所有模式具有相同的呼叫介面，引用者不因模式改變而失效。

引用與型別保護涵蓋資格條件、分支條件、動作引數與候選引數。複製巨集會重建參數與步驟／候選 UUID，重連自己的參數引用，保留其他巨集與變數引用。環境匯入會重連資格條件中的環境變數與各呼叫位置的環境定義。

## Runtime 與模擬

Runtime 在每種巨集上輸出非空的 `eligibility`，省略無限制條件。保留參數 UUID、條件引用及呼叫順序；候選陣列直接存巨集呼叫，省略編輯器候選 id 與 task 包裝。

Runtime 必須在直接呼叫時檢查資格，候選選中後則沿用已求值引數與資格結果。單一時段及全天模擬使用同一規則，顯示資格結果、略過內容與未求值候選。流程控制任務沿用原事件來源優先權；整次執行共用運算與巢狀上限。
