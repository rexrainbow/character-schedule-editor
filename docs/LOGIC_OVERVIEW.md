# 時段行程邏輯一覽

時段行程名稱列下方提供預設收合的「邏輯一覽」。展開後以唯讀文字即時呈現目前草稿，包含一般分支及直接優先候選。獨立編輯器與日／周行程內的時段編輯視窗共用此功能。

顯示深度有「摘要」「展開一層」「全部展開」。摘要顯示目前層級的條件與任務名稱；展開一層顯示直接引用的任務巨集內容；全部展開遞迴顯示到一般或內建任務。計算式巨集依同樣深度展開，以名稱加大括號保留來源；分支計算式保留 IF／ELSE 與各結果。

優先候選標示「第一個符合者執行」，條件取自被引用巨集的資格條件。無資格限制者顯示 ELSE，後方候選仍列出並提示前方已有無限制候選。一般分支沿用 IF／ELSE IF／ELSE；巢狀優先候選與巨集步驟以縮排保留層級，不攤平成另一套執行規則。

呼叫列顯示參數名稱及實際傳入的 expression，內部參數引用代入該內容，不計算 expression 的結果。一般任務及內建任務使用目前顯示名稱；變數使用完整點分路徑。未選取任務、未設定引數或缺失值以對應文字標示，尚未完成的草稿仍能查看。

此功能只呈現靜態規則，不讀取模擬變數值、不執行任務，也不宣稱哪個條件成立；實際路徑交由模擬處理。循環引用與過深／過大的展開會停止並顯示提示。

收合狀態及展開深度保存在瀏覽器 localStorage，屬於介面偏好，不寫入專案、環境或 runtime JSON。文字自動換行，使用既有編輯區捲動，不新增內層捲軸。`logicOverviewModel.js` 負責產生文字，`LogicOverview.jsx` 負責共用介面。
