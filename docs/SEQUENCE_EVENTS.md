# 周序列疊加事件組

每個事件組引用一個具名共用日行程，依日期及週期疊加於主要日行程，不改寫周行程或 Day Override。可只填日開始事件，也可包含日內其他執行位置；所有事件內容共用日行程編輯器。

## 管理與日期選擇

周序列名稱列提供「事件管理（組數）」。面板內清單及編輯區可新增、複製、刪除事件組，選擇日行程、起訖日期、週期與優先權。整個面板採草稿，套用才提交；取消捨棄全部修改。複製產生新 UUID，獨立保留規則及日行程引用。

事件名稱 display_name 與 engine_key 位於事件日行程上方，新增預設空白。首次選取日行程且名稱空白時，自動填入來源名稱；手動輸入的名稱不因改選來源而覆蓋。套用時仍空白則採目前來源名稱，保存後為事件獨立名稱，來源更名不連帶修改它。engine_key 選填，不繼承來源；加入全域重複警告，完整專案仍可儲存，runtime 匯出要求唯一。複製事件組名稱加上「 (副本)」並清空 key；複製整個周序列時保留事件名稱但清空各事件 key。

「事件日行程」及「計數日行程」以圖示＋名稱呈現按鈕，點擊後切換同一個 dialog 為選擇面板，不在原表單內展開清單。面板可搜尋、依標籤篩選，顯示完整名稱、圖示、標籤及目前選取項目。點擊選項立即返回，取消或 Escape 保留原值，並將焦點還給原按鈕；事件草稿與原表單捲動位置保留。清單不含提示用的「選擇共用日行程」項目。未選取時只在按鈕顯示提示，不自動選第一筆；必須選擇有效來源才可套用。

日期使用「周次 × 星期」概要選擇器，顯示 Day N、目前起點／所選日期及命中日期，停留可查看當天主要日行程名稱。每頁八周，長序列可翻頁；窄螢幕在日曆內水平捲動，不疊加第二個 modal。結束日期不能選在事件開始之前。

週期為非負整數：0 僅一次，結束日跟隨開始日且不另編輯；1 每天；7 表示每周同一天。正週期由事件開始日起算，結束日包含當天，但本身不一定命中。由單次切換為週期時，結束日預設為序列結束日（不早於事件開始）。

事件類型可選單次、週期或機率。週期的間隔至少為 1，機率設定百分比及冷卻天數。後兩種提供「計數依據」選擇全部日期、指定共用日行程或指定標籤；後兩者提供相應選擇器。指定日行程與標籤互斥，一次只選一個。舊 skip_weekdays 及 interval_days: 0 格式不提供遷移。完整格式及機率規則見 [PROBABILITY_EVENTS.md](./PROBABILITY_EVENTS.md)。

單次模式隱藏計數條件及結束日，只在指定起點執行。週期模式先套用 Day Override 取得當天生效的主要日行程，再比對 UUID 或標籤；不符合的日期不計數、不執行。從第一個符合日期執行，之後每隔 N 個符合日期執行（第 1、1+N、1+2N… 個）；開始日不符合則順延首次執行。空白主要來源只符合全部日期，週內自訂來源可依標籤符合，但不會以原來源 UUID 符合指定日行程。疊加事件與接管結果不參與計數。日曆、圖示、次數與模擬共用算法，序列有效範圍只裁切，不重算相位。機率事件的圖示及次數代表候選日期，單日模擬另以發生／不發生選單決定是否加入。

標籤不再使用時仍保留事件規則，期間沒有符合日期就顯示零次與提示，不自動改成全部日期。修改標籤、主要日行程、周來源或覆蓋後，日期預覽同步重算。指定不存在或匿名的計數日行程、空標籤或不合法規則阻擋套用與匯入。

改變開始日會平移結束日，保留期間長度及週期；移動後超出序列時顯示欄位錯誤並阻擋套用，須手動修正，絕不自動截短。變更結束日則只調整期間長度。面板顯示總命中次數與有效執行範圍內次數。

## 日期格

每周列加高，在主要日行程上方保留圖示列。每格最多顯示兩個事件圖示，其餘用 +N 開啟當日完整清單；＋按鈕以該日為起點新增事件組。事件有自己的圖示，可由來源日行程初始化後獨立修改；停留提示名稱、期間、規則與優先權，點擊直接選中來源事件組，修改的是整筆規則。機率事件以虛線框表示候選。

圖示按優先權由高至低排序，相同優先權依建立順序。第一個負優先權圖示前以分隔線表示主要日行程的執行位置；完整順序可於管理面板查看優先權及先／後執行說明。範圍外的命中圖示變暗，設定仍保留且可編輯。

停留於事件圖示或以鍵盤聚焦時，使用與主要日行程相同的資訊面板，保留事件名稱、間隔、開始／結束與優先權，另列來源日行程及各時段／開始／結束事件。面板標題旁的跳轉圖示可直接開啟來源日行程，時段行程旁的圖示可開啟其定義；點擊事件圖示本身仍開啟事件組管理。面板可移入操作、以 Escape 關閉。

一般圖示提示四行：事件名稱、規則、開始—結束、優先權；名稱及圖示使用事件自身欄位。機率事件另提示其為候選事件。

## 固定時間軸與周列操作

日期固定為周序列的位置（第幾周＋星期），不引用周列 uid。移動、取代、插入或複製主周行程，不移動、複製或延長事件規則。修改序列開始日只影響 Day N 及有效次數，不重設事件週期。

刪除周列（或刪除被引用的來源周）使事件起點／終點超出剩餘序列時，先提示受影響事件組數，確認才移除這些完整事件組；取消不修改任何資料。仍在範圍內的事件保留原日期位置。空序列不保留無法定位的事件組。

刪除共用日行程時，若被指定為計數對象，提示引用規則數量並阻擋刪除，須先更換計數對象。單純被事件內容引用時，沿用警告後移除相關整組規則。複製周序列會產生新的事件組 UUID，日期、週期與優先權不變。

## 資料與 runtime

專案 `week_sequences` 與 runtime `sequences` 均可含選填 `event_groups` 陣列；省略等同空清單。範例：

```json
{
  "event_groups": [
    {
      "id": "56ba4fd6-12fc-4f24-99cc-b1d75d790071",
      "kind": "periodic",
      "display_name": "例行巡視",
      "engine_key": "event.routine_inspection",
      "day_schedule_id": "0b334bfd-a4ca-414d-8030-fc1ac9716200",
      "start": { "week_number": 1, "weekday": "wed" },
      "end": { "week_number": 3, "weekday": "fri" },
      "interval_days": 7,
      "count_filter": { "kind": "all" },
      "priority": 0
    }
  ]
}
```

陣列順序即相同優先權的建立順序，不另存時間戳。事件名稱及圖示獨立保存；runtime 不輸出圖示。匯入／提交檢查 UUID、事件組 ID 唯一性、共用日引用、整數週期及優先權、機率及冷卻設定、日期落在實際周列範圍內、起訖順序與事件引用契約，錯誤指出欄位位置。

事件組另輸出 display_name 與選填 engine_key；runtime 的空白 key 省略。非空 key 可透過 exports 取得 `{kind: "eventGroups", id, sequence_id}`，同時指出事件組及所屬周序列。事件組 UUID 在整個專案內不可重複。

週期事件在計數依據為全部日期時，Engine 以周列位置與星期計算絕對日索引，滿足 `(目前日索引 - 起點) % interval_days == 0` 且位於事件起訖範圍者命中；單次事件只比對起點。另以序列開始／結束日限制實際執行，但保留原週期相位。Day Override 先決定主要日行程，再加上事件；主要日行程未指定或覆蓋為空，仍可執行符合規則的事件。不同事件組引用相同日行程時不去重。

count_filter 的三種結構為 `{kind: "all"}`、`{kind: "day", day_schedule_id: UUID}`、`{kind: "tag", tag: 標籤字串}`。省略視為 all。指定日行程或標籤時，Engine 應將索引差改為「事件起點至目前日期（含當天）的符合日期數 − 1」，且目前日也必須符合；非負計數位置能整除 interval_days 才命中。不得先按日曆產生週期再過濾。專案與 runtime Schema 限制互斥欄位；runtime 的具名日與週內匿名日都輸出 tags，缺少標籤時為空陣列。

每個日內執行位置分別合併：優先權正數由大到小、0、主要日行程、-1、-2……；相同值依陣列順序，空位置略過。不是先完整執行一個日行程再執行下一個；前面的變數更新可供同位置後續任務及後續位置讀取。

事件或主要日行程可呼叫 [流程控制任務](./FLOW_CONTROL_TASKS.md)，動態取消本時段或本日後續的低優先指派；同優先權與目前來源保留，已執行內容不回復。優先權 0 的事件可取消主要日行程；主要日行程可取消負優先權事件。

[模擬模式](./SIMULATION.md) 支援選擇周序列某日，自動解析覆蓋、正向計數週期與優先權，依日內位置合併全天行程。每個有效日期的 Play 圖示可直接開始設定該日模擬。整天共用測試變數狀態，外部 engine 任務只記錄呼叫，不自動推進到下一天。
