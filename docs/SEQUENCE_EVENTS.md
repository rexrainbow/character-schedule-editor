# 周序列疊加事件組

每個事件組引用一個具名共用日行程，依日期及週期疊加於主要日行程，不改寫周行程或 Day Override。可只填日開始事件，也可包含日內其他執行位置；所有事件內容共用日行程編輯器。

## 管理與日期選擇

周序列名稱列提供「事件管理（組數）」。面板內清單及編輯區可新增、複製、刪除事件組，選擇日行程、起訖日期、週期與優先權。整個面板採草稿，套用才提交；取消捨棄全部修改。複製產生新 UUID，獨立保留規則及日行程引用。

事件名稱 display_name 與 engine_key 位於事件日行程上方，新增預設空白。首次選取日行程且名稱空白時，自動填入來源名稱；手動輸入的名稱不因改選來源而覆蓋。套用時仍空白則採目前來源名稱，保存後為事件獨立名稱，來源更名不連帶修改它。engine_key 選填，不繼承來源；加入全域重複警告，完整專案仍可儲存，runtime 匯出要求唯一。複製事件組名稱加上「 (副本)」並清空 key；複製整個周序列時保留事件名稱但清空各事件 key。

日行程選擇器以圖示＋名稱呈現按鈕及每個選項，可搜尋，清單不含提示用的「選擇共用日行程」項目。未選取時只在按鈕顯示提示，不自動選第一筆；必須選擇有效來源才可套用。

日期使用「周次 × 星期」概要選擇器，顯示 Day N、目前起點／所選日期及命中日期，停留可查看當天主要日行程名稱。每頁八周，長序列可翻頁；窄螢幕在日曆內水平捲動，不疊加第二個 modal。結束日期不能選在事件開始之前。

週期為非負整數：0 僅一次，結束日跟隨開始日且不另編輯；1 每天；7 表示每周同一天。正週期由事件開始日起算，結束日包含當天，但本身不一定命中。由單次切換為週期時，結束日預設為序列結束日（不早於事件開始）。

週期下方可勾選「不計入週期的星期」，以 skip_weekdays（預設 []）保存。排除日不執行且不推進計數；開始日若被排除，從第一個可計數日的第 0 天執行，之後每隔 N 個可計數日執行。結束日期仍固定，不補償延後。例如星期五起、間隔 3、跳過六日，命中星期五、下周三、再下周一。排除六日時，間隔 5 才是每周相同工作日，7 不再代表每周。

單次模式停用勾選但保留設定，仍在指定起點執行，不套用排除星期。週期模式全部七天排除時阻擋套用；若有限期間剛好沒有可計數日，則合法但顯示零次。日曆標記、圖示、次數與四行提示共用同一套算法，序列有效範圍只裁切執行，不重新計數。

改變開始日會平移結束日，保留期間長度及週期；移動後超出序列時顯示欄位錯誤並阻擋套用，須手動修正，絕不自動截短。變更結束日則只調整期間長度。面板顯示總命中次數與有效執行範圍內次數。

## 日期格

每周列加高，在主要日行程上方保留圖示列。每格最多顯示兩個事件圖示，其餘用 +N 開啟當日完整清單；＋按鈕以該日為起點新增事件組。圖示沿用日行程圖示，停留提示名稱、期間、週期與優先權；點擊直接選中來源事件組，修改的是整筆規則。

圖示按優先權由高至低排序，相同優先權依建立順序。第一個負優先權圖示前以分隔線表示主要日行程的執行位置；完整順序可於管理面板查看優先權及先／後執行說明。範圍外的命中圖示變暗，設定仍保留且可編輯。

停留於事件圖示或以鍵盤聚焦時，使用與主要日行程相同的資訊面板，保留事件名稱、間隔、開始／結束與優先權，另列來源日行程及各時段／開始／結束事件。面板標題旁的跳轉圖示可直接開啟來源日行程，時段行程旁的圖示可開啟其定義；點擊事件圖示本身仍開啟事件組管理。面板可移入操作、以 Escape 關閉。

圖示提示固定四行：事件名稱、間隔、開始—結束、優先權；名稱使用事件自身 display_name，圖示仍取自引用日行程。

## 固定時間軸與周列操作

日期固定為周序列的位置（第幾周＋星期），不引用周列 uid。移動、取代、插入或複製主周行程，不移動、複製或延長事件規則。修改序列開始日只影響 Day N 及有效次數，不重設事件週期。

刪除周列（或刪除被引用的來源周）使事件起點／終點超出剩餘序列時，先提示受影響事件組數，確認才移除這些完整事件組；取消不修改任何資料。仍在範圍內的事件保留原日期位置。空序列不保留無法定位的事件組。

刪除共用日行程時，警告包含事件組引用數，確認後移除相關整組規則。複製周序列會產生新的事件組 UUID，日期、週期與優先權不變。

## 資料與 runtime

專案 `week_sequences` 與 runtime `sequences` 均可含選填 `event_groups` 陣列；省略等同空清單。範例：

```json
{
  "event_groups": [
    {
      "id": "56ba4fd6-12fc-4f24-99cc-b1d75d790071",
      "display_name": "例行巡視",
      "engine_key": "event.routine_inspection",
      "day_schedule_id": "0b334bfd-a4ca-414d-8030-fc1ac9716200",
      "start": { "week_number": 1, "weekday": "wed" },
      "end": { "week_number": 3, "weekday": "fri" },
      "interval_days": 7,
      "skip_weekdays": [],
      "priority": 0
    }
  ]
}
```

陣列順序即相同優先權的建立順序，不另存時間戳。事件名稱獨立保存，圖示由共用日行程解析；runtime 不輸出圖示。匯入／提交檢查 UUID、事件組 ID 唯一性、共用日引用、整數週期及優先權、日期落在實際周列範圍內、起訖順序與單次事件同日規則，錯誤指出欄位位置。

事件組另輸出 display_name 與選填 engine_key；runtime 的空白 key 省略。非空 key 可透過 exports 取得 `{kind: "eventGroups", id, sequence_id}`，同時指出事件組及所屬周序列。事件組 UUID 在整個專案內不可重複。

Engine 以周列位置與星期計算絕對日索引，滿足 `(目前日索引 - 起點) % interval_days == 0` 且位於事件起訖範圍者命中；週期 0 只比對起點。另以序列開始／結束日限制實際執行，但保留原週期相位。Day Override 先決定主要日行程，再加上事件；主要日行程未指定或覆蓋為空，仍執行命中的事件。不同事件組引用相同日行程時不去重。

有 skip_weekdays 時，Engine 應將上述索引差改為「由事件起點至目前日（含當天）的可計數日數量 − 1」，且目前星期必須未被排除；非負計數位置能整除 interval_days 才命中。不得先按日曆產生週期再移除星期。專案與 runtime Schema 均檢查星期枚舉與陣列唯一性；匯入另拒絕正週期全部排除的規則。

每個日內執行位置分別合併：優先權正數由大到小、0、主要日行程、-1、-2……；相同值依陣列順序，空位置略過。不是先完整執行一個日行程再執行下一個；前面的變數更新可供同位置後續任務及後續位置讀取。

事件或主要日行程可呼叫 [流程控制任務](./FLOW_CONTROL_TASKS.md)，動態取消本時段或本日後續的低優先指派；同優先權與目前來源保留，已執行內容不回復。優先權 0 的事件可取消主要日行程；主要日行程可取消負優先權事件。

[模擬模式](./SIMULATION.md) 支援選擇周序列某日，自動解析覆蓋、週期、排除星期與優先權，依日內位置合併全天行程。每個有效日期的 Play 圖示可直接開始設定該日模擬。整天共用測試變數狀態，外部 engine 任務只記錄呼叫，不自動推進到下一天。
