# 內建流程控制任務

任務定義清單與使用任務的選單分為「變數操作」「流程控制」「引擎任務」；任務巨集另列。分類由固定範本決定，不存入使用者定義。流程控制範本固定無參數、不能刪除或複製；環境模式可修改圖示、display_name 與 engine_key。

| 專案 builtin | 預設名稱 | 範圍 |
| --- | --- | --- |
| `cancel_lower_priority_slot` | 取消本時段低優先行程 | 從現在起，本時段的剩餘開始／主行程／結束指派 |
| `cancel_lower_priority_day` | 取消本日後續低優先行程 | 從現在起，直到日結束的所有剩餘指派 |

專案任務呼叫為 `{ "builtin": "cancel_lower_priority_slot" }` 或 `{ "builtin": "cancel_lower_priority_day" }`，沒有 target、value 或 arguments。時段分支、分支巨集與序列巨集步驟均可使用，原有巨集呼叫限制維持。

## 執行語意

只有周序列某日的整體執行器能處理取消。每次命中控制任務，以呼叫來源的優先權與目前階段建立取消規則；巨集內繼承呼叫它的事件／主日行程來源。控制任務不終止目前巨集的後續步驟，也不取消目前來源日行程的後續內容。

其他來源只有優先權嚴格較低才取消，同值即使建立較晚也繼續。順序為正優先權事件、0 優先權事件、主日行程、負優先權事件。因此 0 可以取消主日行程，主日行程可取消負優先權事件；負優先權事件不能取消主日行程。

取消僅影響尚未執行的指派，不回復先前變數修改。被取消的整筆時段指派不再求值任何條件、計算式、引數或巨集。多個控制規則累積作用，符合任一者即略過；同時符合多個規則時，紀錄顯示第一個適用的取消來源。

本時段規則僅套用時段開始／主行程／結束，進入下一時段失效，也不包含日結束事件。於日開始／日結束執行此任務時，記錄未生效提示。本日規則可於日開始使用，涵蓋當天的日結束；下一天清空所有取消規則。每次模擬重新建立規則，不跨執行保留。

單一時段行程模擬記錄呼叫並提示需要周序列某日上下文，不造成失敗、不取消目前巨集步驟。控制未被條件分支選中時，不建立取消規則。

## 模擬紀錄

全天計畫仍列出原本可能執行的來源。實際執行紀錄顯示控制任務是否生效；被取消者標為「已取消，不求值」，另列來源事件／主日行程名稱、控制任務名稱、範圍、發生階段及任務資料位置。可沿用來源日行程與時段行程的跳轉按鈕。

## Runtime 契約

```json
{
  "task_key": "使用者設定的 engine_key",
  "flow_control": "cancel_lower_priority",
  "scope": "slot"
}
```

另一範本為 `scope: "day"`。控制種類與範圍是固定語意，不隨名稱、圖示或 engine_key 改變。engine 必須由周序列執行器處理此指令，使用目前來源優先權及階段；不能將它當成副作用未知的一般任務呼叫。

實際引用的範本仍須有唯一且非空的 engine_key。`environment_requirements.tasks` 列出此 key、顯示名稱與空參數陣列；呼叫本身保留 flow_control 與 scope 供 runtime 辨識。完整專案與環境匯入／匯出保留範本的自訂顯示資訊。project、environment 與 runtime schema 均包含對應結構限制。
