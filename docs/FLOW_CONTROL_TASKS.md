# 行程接管

流程控制只提供 `schedule_takeover`（行程接管），取代舊的五種取消指令。任務清單與選單仍分為變數操作、流程控制、引擎任務。範本不能刪除或複製；環境模式可修改名稱、圖示、engine_key 及參數顯示名稱，參數數量與種類固定。

## 參數

| 參數 | 名稱 | 編輯方式 |
| --- | --- | --- |
| `condition` | 接管條件 | 共用條件編輯器，支援比較、ALL、ANY、變數／計算式巨集／巨集參數引用 |
| `scope` | 接管範圍 | `slot` 本時段、`day` 本日後續 |
| `target` | 接管對象 | `main` 主要日行程、`lower_priority` 較低優先行程 |

新增呼叫預設為 `true == true`、本日後續、主要日行程。布林值可透過「該變數／參數／計算式巨集 == true」作為條件。範圍與對象只能從固定選單選擇。

## 執行語意

每次呼叫只求值一次條件。成立時取消指定對象，不成立時取消目前日行程實例；兩種結果都使用相同範圍。只影響尚未執行的指派，不撤銷先前修改。目前時段行程與巨集剩餘步驟繼續完成。

- 本時段：包含本時段剩餘的開始、時段行程與結束。失敗也只退出本時段，下一時段可再次執行。日開始／日結束階段不生效。
- 本日後續：包含從現在直到日結束的剩餘指派，可在日開始使用。
- 主要日行程：取消當天生效的主要來源，包含 Day Override，不比較呼叫者優先權，所有疊加事件保留。主要來源自己也能呼叫。
- 較低優先行程：只取消優先權嚴格較低的來源，目前來源及同優先權保留。0 優先事件高於主要來源，主要來源高於負優先事件。
- 失敗退出：以主要來源或事件組 UUID 識別自身，不以日行程 UUID 識別；引用相同日行程的其他實例不受連帶影響。

取消規則累積，不會恢復已取消內容，新的一天或新一次模擬清空。被取消指派不再求值任何條件、引數或任務。單一時段模擬會求值並記錄呼叫，但提示缺少周序列某日上下文，不產生取消效果。

例如設備檢修事件於日開始呼叫，條件為「設備損毀 == true」、範圍本日後續、對象主要日行程：異常時保留檢修並取消主要來源；正常時退出檢修，主要來源繼續。

## 資料契約

```json
{
  "builtin": "schedule_takeover",
  "condition": {
    "kind": "comparison",
    "operand_a": { "type": "constant", "value": true },
    "comparator": "==",
    "operand_b": { "type": "constant", "value": true }
  },
  "scope": "day",
  "target": "main"
}
```

Runtime 呼叫保留 condition、scope、target，將 builtin 改為 `task_key`（自訂 engine_key）及 `flow_control: "takeover"`。環境變數照原規則轉成 environment_reference，巨集參數保留區域作用域。engine 由周序列執行器處理此控制。

引用的範本須有唯一且非空的 engine_key。`environment_requirements.tasks` 列出三個參數的名稱與型別（boolean、string、string）；範圍及對象的合法 enum 由 runtime action schema 限制。名稱與 key 不改變控制語意。

三份 Schema 已移除舊取消呼叫與範本設定，不做舊資料遷移；舊格式會拒絕匯入並指出位置。條件引用參與刪除、型別變更、參數複製重映射及環境替換檢查。

## 模擬與邏輯一覽

模擬顯示條件求值、接管成功／失敗或未生效原因；取消者保留來源、範圍與資料位置。邏輯一覽以 IF／ELSE 顯示「接管：範圍／對象」與「退出：範圍／目前日行程實例」，只呈現靜態規則。
