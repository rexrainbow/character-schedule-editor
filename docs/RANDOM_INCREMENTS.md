# 隨機增加值與整數變數

「增加數值」內建任務新增「隨機幅度（±）」數值運算元，可使用常數、變數、計算式巨集及目前巨集的數值參數。省略 `random_amplitude` 等同 0；幅度為 0 時不抽取亂數，保留原本的增加數值行為。幅度必須為非負有限數字，動態運算結果不合法時，在寫入前回報錯誤並指出位置。

計算方式為 `目前值 + 增加值 + 隨機偏移`。例如增加值 10、幅度 2，偏移介於 -2 與 2，增加量介於 8 與 12。一般數值變數使用均勻實數分布；電腦抽樣使用左含右不含區間。僅限整數的目標使用均勻整數分布，幅度 2 時可抽到 -2、-1、0、1、2；幅度有小數時，先取幅度的整數部分作為抽樣範圍，並非抽出小數後截斷。

## 僅限整數

環境層及應用層的數值變數新增 `integer_only` 布林屬性，省略表示 false。編輯器在初始值附近提供「僅限整數」checkbox；群組、其他型別及計算式巨集不適用。使用者編輯模式中的環境定義維持唯讀。

啟用後，初始值及有設定的最小值、最大值必須為整數。不自動調整已有的小數，必須修正後才能提交或匯入。變更為非數值型別時，清除這個屬性及上下限。

runtime 寫入數值時，先確認有限數字，再依 `integer_only` 朝零截斷小數，最後套用最小值、最大值。例如 -3.8 寫入整數變數為 -3。這個順序適用於設定變數、增加數值、重設初始值及 runtime 其他數值寫入。一般運算與計算式巨集的中間結果不受影響。

## 儲存與執行資料

專案、環境與 runtime Schema 皆支援此屬性。runtime 的完整變數樹及環境變數需求資訊保留 `integer_only`，增加數值任務保留選填 `random_amplitude` 運算元。任務定義固定為三個參數：`target`、`value`、`random_amplitude`；參數顯示名稱可自訂。引用檢查與複製亦處理幅度中的變數、巨集參數。

```json
{
  "builtin": "increment_variable",
  "target_variable_id": "<variable UUID>",
  "value": { "type": "constant", "value": 10 },
  "random_amplitude": { "type": "constant", "value": 2 }
}
```

## 模擬

時段與全天模擬新增「亂數種子」，預設為 `1`。相同輸入與種子可重現偏移；全天執行共用同一串亂數。種子僅屬模擬工作階段，不寫入專案、環境或 runtime 匯出。機率事件仍由使用者指定發生或不發生。

非零幅度的執行紀錄顯示增加值、幅度及實際抽取偏移；小數截斷與範圍限制分別顯示。測試輸入也須符合整數及上下限要求。實際 engine 可選擇自己的亂數產生器，但應遵循上述分布與寫入順序；模擬的種子演算法不是 engine 契約。整數抽樣若超出可安全表示的範圍，模擬會明確回報錯誤。
