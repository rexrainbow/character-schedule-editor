# 連續模擬

「模擬模式」提供「行程模擬」與「連續模擬」小分頁。前者檢查單一時段／單日的條件與執行流程；後者觀察數天到數周的事件、變數累積與週期效果。兩者共用 `src/runtime/`，不另寫一套執行器。

## 輸入與執行

周序列編輯器的「連續模擬」按鈕會切換至此分頁並選取該序列，不自動執行。天數、種子與測試輸入保留；同一目標保留結果，切換目標則清空舊結果。連續模擬選單旁的「回到周序列編輯」icon 會返回目前選單指定的序列，並清除周序列搜尋條件。執行中返回會中止執行並保留完整日期；編輯專案仍會使舊結果失效。

- 選擇周序列、執行天數、初始變數與亂數種子。預設 28 天，單次支援 1～366 天。
- 固定從序列開始日執行；有限序列到結束日即停止，無限重複也必須設定模擬天數。
- 所有事件發生機率、候選權重／依序選擇、數值隨機幅度都由 runtime 正常決定，不採用單日模擬的手動事件選項。相同專案、輸入及種子可重現結果。
- 環境進度變數自動綁定，不能手動修改。其他唯讀變數仍可設定獨立測試初值。
- 使用專案初始值作為「重設初始值」任務的基準；修改測試輸入不改變此基準。
- 外部環境任務只記錄呼叫，不執行 engine handler；無法推測外部副作用時顯示既有提示。

執行期間顯示進度並禁止重複啟動，可取消。取消或失敗時只保留**完整執行完畢的日期**；當天只做了一半的任務不列為日終結果。輸入變更、專案變更或離開分頁會中止舊執行，過期結果不回填。兩個分頁的輸入及結果分開保存於 App session，不修改專案，也不隨專案匯出。

## 每日與周摘要

桌面可透過「輸入」標題旁的「收合輸入」icon 隱藏左欄，留下窄列的「展開輸入」按鈕，讓結果區及圖表使用其餘寬度。周序列、天數與執行／取消按鈕保持在上方。收合不重設變數、種子、結果、事件標記或選取狀態，也不停止執行；此偏好只存於模擬 session。窄螢幕沿用「輸入／結果」切換，即使桌面先前已收合，仍可開啟輸入。

結果分成「每日紀錄／周摘要／趨勢圖」三個小分頁。每日表格顯示實際日期、事件以及所選變數的日終值與當日差值。最多可選六個欄位；完整快照仍保留全部變數。每頁 14 筆，結果區負責捲動，格子不自行捲動。

點擊日期可查看：

- 主要日行程、實際發生事件及抽中的日行程，依執行順序列出並可跳轉來源。
- 每個變數的日初／日終值與變化量。
- 按行程來源、按任務名稱彙總的已提交變更。數值顯示實際增減量，包含上下限與整數限制的結果；布林／文字顯示前後值及寫入次數。
- 時段行程與最小任務的呼叫次數、被中斷／放行略過的位置數，以及新預約事件。
- 可展開的完整日終變數快照。

周摘要依實際周曆分組，星期日 `day.end` 完成後包含完整周結果；不完整的開始周、結束周、取消區間標註「部分周」。點擊周可看全部變數的周初／周末值、實際差值、事件次數與時段行程執行次數，並可進入該周最後一天的詳細資訊。

事件「發生」代表已成為當日來源，不等於其每個位置均獲執行；較高優先事件可能中斷它。略過數統計的是執行位置，並非未選中分支或任務數。數值變化只統計實際提交的變更，不將未執行分支算入。

## 數值趨勢圖

使用 [Recharts](https://github.com/recharts/recharts) 產生 SVG 折線圖，套件隨專案打包，不使用外部 CDN。圖表模組在第一次開啟趨勢圖分頁時才載入。Recharts 與 react-is 的 MIT 授權檔案位於 `public/licenses`，建置時一併輸出。

- 僅列出數值變數，預設沿用每日表格所選的數值欄位，勾選後的圖表選擇獨立保存。
- 每個變數各一張圖，使用自己的 Y 軸刻度，所有圖共用實際經過天數的 X 軸。
- Day 0 使用該次執行捕捉的原始測試輸入，Day 1 起使用已完成日期的日終 snapshot。切換欄位或分頁不重新執行模擬。
- 使用直線連接資料點，不平滑插值。缺少或非有限數值保留為斷點，不補零；取消／失敗當天的部分結果不加入折線。
- 游標或鍵盤方向鍵可查看某天的數值，各圖同步對應相同天數。提示依序顯示 Day N、該日的星期、變數值；星期取自實際模擬日期，不假定 Day 1 是周一。Day 0 以「初始值」代替星期。停用繪圖動畫，沿用介面的深色樣式及語系。
- 點擊 Day 1 起的資料點會開啟既有的當日詳細資訊；也可在圖表上使用方向鍵選取日期，再按 Enter／空白鍵。Day 0 不開啟日行程面板。
- 「事件標記」清單取自本次完整日期中實際發生的事件，包含預約事件。可勾選並使用既有八色選項調整標記顏色；設定只保留在模擬 session，不寫入專案。
- 所有變數圖在相同日期顯示彩色點；同日多個選取事件以多色圓環表示，超過三個時另顯示 `+N`。提示列出全部選取事件名稱，折線本身仍使用原本顏色。
- 標記表示事件已成為當日來源，不表示所有任務都執行；若需確認中斷或放行，請開啟當日詳情。

純資料轉換與事件彙整位於 `src/simulation/trends.js`；Recharts 僅由 `src/gui/components/ContinuousTrendCharts.jsx` 使用。資料點與事件共用穩定的 `day` 座標，不必更改 runtime。

目前仍顯示整個模擬區間，尚未加入日期視窗或橫向捲動。模擬天數上限與顯示精度是不同問題；長區間的下一步可採共用日期視窗、前後移動與範圍選擇，再依效能調整可模擬天數。

## 詳細重跑與 checkpoint

連續執行使用 `diagnostics: false`，由外部 collector 訂閱 `variable.change`、`task.completed`、`assignment.end`、`assignment.skipped` 等生命週期事件形成摘要。runtime 不保留歷史。

模擬器在**每一天開始之前**保存 checkpoint，內容包含變數、亂數、機率冷卻、依序候選、預約與前一天進度。按「檢查當日執行流程」時，使用同一個 Program 與此 checkpoint 建立獨立 runtime，重新選取事件並執行一天，啟用 `diagnostics: true`，再由共用 `SimulationTrace` 顯示細節。

不能只把日初變數送入普通單日模擬，否則無法重現當時的亂數與跨日狀態。詳細重跑不會改變連續模擬結果、其亂數或快照。關閉視窗會取消尚未完成的詳細重跑。

歷史與 checkpoint 目前只在記憶體中，重新整理頁面即消失；不提供任意日期起跑、跨重新整理續跑或歷史匯出。

## 程式介面

`src/simulation/continuous.js`：

```js
const result = await simulateContinuous(draft, {
  sequenceId,
  days: 28,
  seed: '1',
  values,
  signal,
  onDay: progress => { /* 完成一整天後更新畫面 */ },
});

const detailed = await replayContinuousDay(draft, result, result.days[6], t, { signal });
```

`status` 為 `running`、`completed`、`cancelled` 或 `failed`。`days` 保存每日完整結果與執行前 checkpoint；`weeks` 保存周彙總；`errors` 保留驗證／執行錯誤位置。`finalValues` 是最後完整一天的變數值，不包含取消／失敗當天的部分變更。

驗證：`tests/continuousSimulation.test.js`、`tests/browser/continuousSimulation.spec.js`，另保留既有單日與時段模擬測試。
