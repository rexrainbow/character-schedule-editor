# Markdown 行程報告

在使用者編輯模式右上角「匯出」選單選擇「行程報告（Markdown）」，再選擇是否包含未引用內容，下載 `character-schedule-report.md`。報告使用目前介面語系，支援繁體中文與英文，涵蓋整份專案的所有周序列，不受目前頁面或選取的周序列影響。周序列操作選單不再提供報告匯出。

## 報告內容

1. **周序列**：開始、結束、有效天數，以及每周日期表。日期從開始日起編為 Day 1；開始日前與結束日後保留星期並標示範圍外。每個有效日期列出實際主要日行程、繼承或日覆蓋來源、原日行程、當日事件與來源優先順序。覆寫為空白會明確標示。
2. **事件**：所屬周序列、事件日行程、種類、日期、計數依據、優先權及範圍內次數。週期事件列出間隔，機率事件列出機率與冷卻天數；單次事件省略結束日及計數依據。機率事件於日期表與次數處皆標為候選，未推算歷史冷卻或抽取機率。
3. **日行程**：先列出自訂標籤與內建適用用途（主要／疊加事件／中斷事件），再依序列出日開始、時段開始、時段主內容、時段結束與日結束。多用途完整列出；未選用途顯示「未分類」，省略用途欄位沿用預設「主要」。無自訂標籤顯示「—」。適用用途反映手動設定，不依引用重新分類。空白事件位置省略；空白主要時段保留「未指派」。周內自訂日行程以所屬周與星期命名，同樣列出標籤與用途。
4. **時段行程與任務邏輯**：重用「邏輯一覽」的全部展開，保留巨集名稱、資格條件、實際引數及內部任務。明確事件引用以事件名稱顯示，無任務的時段保留其名稱與無任務指派提示。大型展開沿用既有深度與行數保護，達上限時顯示提示。

來源順序分別套用於日開始、各時段的開始／主內容／結束與日結束，而非先跑完整個高優先日行程，再跑主要日行程。這份報告不執行條件、流程控制、任務或模擬，也不改變變數。

## 引用與格式

共用日行程及時段行程只輸出一次，引用位置可點擊跳到詳細內容。預設列出有效日期的主要日行程、事件使用的日行程，以及報告中引用的原日行程與計數來源日行程；這些日行程的所有已指定時段也會輸出。所有周序列的事件定義都會列出，包含有效範圍內次數為 0 的定義。

「包含未引用內容」會另外列出其餘日行程與時段行程，並標為未引用。同名物件附上識別編號，事件同名時附上周序列與事件序號。UUID 僅用於文件內連結錨點，不作為顯示名稱；不輸出 icon 或 engine_key。

名稱與標籤會跳脫 Markdown／HTML 特殊字元，完整任務邏輯使用縮排程式碼區塊。報告不加入產生時間，因此相同專案、語系與選項產生相同內容，方便版本比較。

## API 與驗證

純 JS 編譯器為 `src/core/reportModel.js`，可由 Web 或 Node.js 使用：

```js
const result = project.exportReport({ includeUnreferenced: false });
// { data: Markdown 字串或 null, errors: [...] }
```

報告匯出前使用完整專案驗證，有錯誤時不產生下載，視窗保留錯誤位置。匯出報告不代表專案已儲存，不會清除未儲存狀態；Cancel 不修改專案。
