# 角色行程編輯器

安排角色何時做什麼，並依角色狀態與事件改變行動。從固定作息開始，再逐步加入條件、任務與模擬。

| 層級 | 用途 | 例子 |
| --- | --- | --- |
| 周序列 | 組合多周，設定起訖、重複與事件 | 工作周無限循環，期間可能感冒 |
| 周行程 | 安排星期一至星期日 | 平日工作，周末休假 |
| 日行程 | 安排各時段及日／時段開始與結束動作 | 上午工作、下午工作、晚上休息 |
| 時段行程 | 定義某個時段的活動，可加入條件選擇 | 體力足夠就工作，否則休息 |
| 任務巨集 | 將任務組成序列、分支、優先或加權隨機候選 | 工作：扣體力、累計出勤 |
| 任務 | 執行一個具體動作 | 增加金錢、設定變數、預約事件 |
| 變數／計算式巨集 | 保存狀態，或依目前狀態計算結果，供各層共用 | 體力、出勤班數、本周薪資 |

## 事件讓作息產生變化

在周序列加入單次、週期或機率事件。房租與薪資結算可疊加執行；感冒與設備檢修可中斷原行程。事件同樣使用日行程定義內容。

## 先簡單安排，再逐步細化

只填時段行程名稱，也能完成一份作息；需要行動邏輯時，再加入任務、巨集與條件。時段行程也可以直接呼叫任務，不必經過巨集。

## 編輯 → 模擬 → 匯出

用單日模擬檢查條件與執行順序，用連續模擬觀察數值趨勢；最後匯出執行資料交給 engine，或以 YAML 藍圖供人類與 agent 編輯。內建變數操作可在模擬中執行；外部任務的實際效果由 engine 提供。
