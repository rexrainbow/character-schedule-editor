# 日行程標籤

具名日行程可有多個手動標籤。名稱列下方顯示標籤膠囊，輸入名稱後按 Enter 或新增按鈕，亦可從既有標籤選單直接加入。輸入去除前後空白，空白與同日重複標籤不新增；標籤區的叉號只移除該日的標籤。

日行程清單搜尋框下方提供單一標籤篩選：全部標籤、未分類、各個標籤，附日行程數量。標籤數量以所有具名日行程計算，與名稱搜尋分開；篩選與名稱搜尋同時生效。點清單標籤亦可篩選，清除篩選只清除標籤條件。清單顯示名稱下方的可點擊標籤。

周行程的日來源、周序列 Day Override 與事件日來源選擇器提供相同篩選。篩選不修改目前引用或選擇，清空／繼承選項仍保留。週內匿名日行程不列入標籤選項與數量。

標籤可用於整理，也可作為事件組的日期計數條件；變更標籤會影響相關事件日期與模擬。標籤不改變優先權或日行程角色，某日仍可同時當主要來源與事件來源。「事件」「主要行程」只是使用者可自行新增的標籤，系統不自動指定。

專案 Schema 的 day_schedule 新增選填 `tags: string[]`，標籤須為非空且已去除前後空白的字串，陣列不得重複。大小寫有別，允許文字中間包含空白。未設定或空陣列都代表未分類；編輯器移除最後一個標籤時省略欄位。匯入不符合的資料會拒絕並指出位置。

專案存讀檔及日行程複製保留標籤，複製陣列獨立；週內自訂日的快照也保留來源標籤。Runtime 的具名日與內嵌匿名日皆輸出 tags，沒有標籤時輸出空陣列，供事件計數使用；不屬於環境設定。篩選僅是介面狀態；新增／複製日行程、匯入／建立專案及跳至日行程時清除標籤篩選，以顯示目標。

第一版不做標籤排序分組、標籤顏色或全域更名。既有標籤從具名日行程彙整，移除最後一筆使用後不再出現在既有標籤選單。
