# Character Schedule Editor

[Open the Web App](https://rexrainbow.github.io/character-schedule-editor/dist/)

## Purpose

Character Schedule Editor is a visual tool for designing character routines and the tasks they perform. Build reusable slot schedules, arrange them into days and weeks, and combine weeks into longer sequences. Use variables and conditional rules to adapt activities to a character's state, then export the resulting data for a game engine or other runtime.

## Interface Features

- **Schedule editors:** Start with day schedules, then organize weeks and week sequences. Type an activity name in a day cell's slot picker and confirm to create and assign it, or reuse an existing schedule. Activities can consist of a name alone; task logic is optional and available in the advanced slot editor. Customize individual weekdays and add day overrides within a week sequence.
- **Day tags:** Organize day schedules with multiple custom tags. Filter the list and day selectors by tag or find untagged schedules, alongside name search. Tags are included in runtime data so recurring events can count matching day schedules.
- **Day purposes:** Mark days for main schedules, overlay events, or interrupt events, with multiple choices allowed. Group and filter the day list by purpose. Pickers start with a matching purpose filter and let you browse all days. These editor hints remain separate from custom tags and never restrict assignments.
- **Conditions and expressions:** Build nested ALL/ANY conditions, comparisons, and arithmetic expressions with visual editors. Reuse numeric or Boolean expression macros in either single-expression or conditional branch mode.
- **Enum definitions and option parameters:** Organize reusable enums into groups in both editing modes. User content can reference provided definitions or its own enums. Task and macro parameters can use custom options or reference a shared enum by UUID. Choose values from dropdowns and forward compatible macro parameters; reference checks protect values already in use.
- **Macro eligibility and priority candidates:** Add optional eligibility conditions to sequence, branch, or priority macros. Keep rules and actions in one definition, and arrange any macro types into a priority list that runs the first eligible candidate. Conditions start collapsed, with summaries and shortcuts to shared definitions.
- **Direct slot candidates:** Start an empty slot schedule with either an ELSE branch or a priority candidate list. Select and order reusable macros directly in the slot editor, without creating a separate priority macro.
- **Day and slot events:** Optionally assign schedules to the start and end of a day or individual time slots. Expand compact event rows to edit them, reuse named activities, or jump to their details. Event assignments are preserved in day copies, week customizations, previews, and runtime exports.
- **Overlay events:** Add one-time, periodic, or probability events to a week sequence. Give each event an icon, name, and optional engine key. Choose dates from a week calendar, count matching day schedules or tags, set priorities, and inspect ordered event icons. Probability events include a percentage and cooldown in eligible days. Event dates stay fixed when the main week schedules move.
- **Event references:** Pass events to tasks and macros using an icon and name picker. Read probability, configured cooldown, or remaining cooldown in expressions, and use the built-in adjustment task to set or increase probability and cooldown settings.
- **Event reservations:** Schedule a one-time runtime event from a task, using a numeric date expression, a fixed or weighted day source, an execution mode, and priority. Day simulation lists the resulting reservations without running future days or changing the project.
- **Event day sources:** Use a fixed day schedule, a weighted random candidate list, or an ordered cycling list. Select candidates in a searchable dialog, edit weights, and reorder with arrow buttons. Single-day simulation lets you choose probability-event occurrence and the exact candidate used.
- **Tasks and macros:** Fill in typed task parameters and reuse sequential or branching task macros. Built-in tasks support variable assignment, increments, Boolean toggles, and resets. Event containers can overlay schedules or interrupt the main schedule and lower-priority events. Each day slot has a dedicated optional release rule, evaluated after its start tasks; a matching rule releases that event for the current slot.
- **Variables and environments:** Organize typed variables into groups, configure initial values and read-only access, and switch between user editing and environment editing. Environment definitions provide the variables and task interfaces available to user content.
- **Simulation:** Test a single slot schedule or a selected day in a week sequence. Preview the main schedule and overlay events, then inspect execution by phase and priority with shared test values throughout the day. Manually choose whether each eligible probability event occurs; the single-day simulator does not infer history or draw random outcomes. Follow conditions, task calls, macro expansion, variable changes, and event-setting adjustments, or jump to source schedules. Reset inputs or use successful variable results for another run without changing the project. External engine task effects are not simulated.
- **Project and runtime files:** Import and export complete projects, import and export environment definitions, and export runtime data for engine integration.
- **Schedule reports:** Export a linked Markdown report of week sequences, events, day schedules, and fully expanded task logic. Optionally include unreferenced content; probability events are marked as candidates.
- **Numeric constraints and randomness:** Configure optional bounds and integer-only variables. Add a random amplitude to numeric increments, and reproduce simulated offsets with a random seed.
- **Navigation and appearance:** Use a dark interface, searchable lists, a shared icon picker, day previews, and shortcuts to referenced schedules. The layout adapts to desktop and mobile screens.
- **Languages:** Switch between English and Traditional Chinese, with the initial interface language selected from browser preferences.
